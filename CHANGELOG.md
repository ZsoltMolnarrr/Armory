# 1.4.0

Requires Spell Engine 1.9.13 or later.

SPELL EXPANSION! Introducing new armor sets for all classes:
- Arcane Wizard: Tempest
- Fire Wizard: Smouldering
- Frost Wizard: Rimeweave
- Priest: Absolution
- Paladin: Lightbringer
- Warrior: Onslaught
- Rogue: Slayer
- Archer: Riftstalker

Each new set is crafted from the same base armor as the class's existing set. The Forgotten upgrade crystal used in the smithing recipe decides which of the two sets you get.

Reworked every 4 piece set bonus. Each set now improves one of its class's two tier 3 spells, so the two sets of a class cover one spell each. The improvements were picked to never overlap with a Skill Tree node of the same spell, so set bonus and skill points stack instead of repeating each other:
- Astral: Arcane Beam releases 2 additional times
- Tempest: Arcane Barrage emitters last 5 sec longer
- Scarlet: increased Meteor critical strike chance
- Smouldering: increased Firestorm radius
- Glacier: Frost Shield also dispels a harmful effect
- Rimeweave: increased Ice Lance critical strike damage
- Avatar: increased Circle of Healing power
- Absolution: increased Penance critical strike chance
- Justicar: reduced Divine Protection cooldown
- Lightbringer: reduced Judgement cooldown
- Deathmantle: reduced Shadowstep cooldown
- Slayer: increased Bear Trap power
- Destroyer: reduced Charge cooldown
- Onslaught: greatly increased Shout damage
- Strider: Barrage arrows pierce 1 additional enemy
- Riftstalker: reduced Spirit Wolf cooldown
